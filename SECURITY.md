# Security / Безопасность

This repository contains public showcase material only. Game source, credentials and runtime infrastructure remain private. There is no public gameplay endpoint or supported release here.

For a suspected vulnerability, use GitHub’s private **Report a vulnerability** form:
https://github.com/bbbbbbalu0420/krco-kitchen-rush/security/advisories/new

Private vulnerability reporting is enabled. Do not post tokens, personal data or exploit details in a public issue. Please state the affected build, expected/observed behavior and a safe reproduction. No bounty, response SLA or support email is currently offered. Support email: **OWNER_INPUT_REQUIRED**.

Для сообщения об уязвимости используйте закрытую форму GitHub по ссылке выше. Не публикуйте ключи, личные данные и детали эксплуатации в открытом issue.
